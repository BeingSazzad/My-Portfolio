# Sazzad Chowdhury — Senior UI/UX Designer & Web Developer Portfolio

A pixel-accurate, token-driven personal portfolio engineered with modern frontend standards, responsive geometry, and smooth 60fps micro-motion. Inspired by the **Visiblo** design system.

---

## ✨ Features

- **Pixel-Accurate Visiblo Aesthetic:** Inter typography scale, dark glassmorphism (`backdrop-filter: blur(25px)`), and signature glowing amber-gold gradients.
- **Persistent Viewport Pinning:** Desktop Profile Card remains locked/fixed while scrolling through the narrative journey.
- **Ambient 3D Liquid Jelly Background:** Smooth looping ambient video backdrop (`jely.mp4`) with dark radial vignette overlays.
- **Circular SVG Preloader:** Progress counter (0% → 100%) with animated strokeDashoffset and smooth exit transitions.
- **Interactive Project Lightbox:** High-resolution modal with zoom transitions, detailed project scope, and keyboard `ESC` dismissal.
- **Continuous Marquee Testimonials:** Smooth infinite ticker with client and peer endorsements (auto-pauses on hover).
- **Responsive Navigation:** Floating desktop quick-dock (`IconBar`) with active scroll-spy indicators and a mobile slide-out drawer (`SidebarDrawer`).
- **Interactive Contact Form:** Validated inputs with success alerts and celebratory confetti interaction.

---

## 🛠️ Tech Stack

- **Framework:** React 18 & TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS & PostCSS
- **Iconography:** Remix Icon (`remixicon`)
- **Interactions:** Canvas Confetti (`canvas-confetti`)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm / pnpm / yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/BeingSazzad/My-Portfolio.git

# Navigate to project directory
cd My-Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
